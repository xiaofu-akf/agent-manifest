# Contributing

Contributions must be narrow, testable and traceable. Do not add secrets, model credentials, copyrighted template assets, scraped prompts, or material whose source and license cannot be verified.

For a manifest change, add a valid example or test case, run `npm test`, and run `npm run validate -- <changed-file>`. For a template record, include a pinned upstream revision and concrete license evidence. Do not claim an asset is redistributable until it has been reviewed.
